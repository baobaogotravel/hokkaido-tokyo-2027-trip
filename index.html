2月7日（日）香港 → 羽田

  1. JL026：參考 HKG 15:35 → HND 20:25（T3）
  2. 機場 → 京急 EX INN：推 東京モノレール T3→天空橋（約¥180）→ HICity口→ゾーンJ徒歩約2分。酒店無機場→酒店免費接駁。
  3. 準備：翌日手提（雪祭暖衣）；大行李可考慮運送 Tomamu；早瞓，翌朝 shuttle 6:00／6:20。

2月8日（一）CTS → 雪祭 → Tomamu（≈15:30）

目標 Tower 約 15:30（おおぞら7）準 15:00 唔 realist。札幌 13:57 發 → トマム 15:26 → shuttle ≈15:31。大通建議 12:50 離，13:45 前到月台。
  1. 酒店 → JL503 → CTS：免費 shuttle 6:00／6:20；JL503 約 07:30→09:00
  2. CTS → 札幌站：快速エアポート約33–37分；約¥1,230；大件放ロッカー
  3. 大通雪祭（壓縮版）：約 12:50–13:00 離大通
  4. おおぞら7 → トマム：13:57→15:26；全指定席；正價約¥5,880。替代：太早おおぞら5 11:46→13:22；太晚とかち5 15:51→17:39
  5. check-in：取 Mina-Mina／木林の湯、霧氷往返券、Ice Village
  6. 15:30 起玩咩：幾乎趕唔切當日霧氷（上り最終約15:30）→ check-in／溫泉／Mina-Mina；17:00–22:00 Ice Village（已包）；霧氷留活動日

2月9日（二）Tomamu · Snowboard 上堂日（推）

唔會一日 Ski 一日 Board一日集中新手 Snowboard 課；另一日活動。9／10 可對調。上堂日若要全日練板＝另買リフト券。
  1. 早餐後去 Adventure Base 3F Ski & Snowboard Academy
  2. 新手 Snowboard Lesson（要預約）：Group 120分主要日語 ¥7,800–8,800；Private 英／日約¥26,300–27,800；可加中文認證雪校
  3. 租賃＋當日リフト券（住宿者優待約¥9,000）；霧氷券≠全日 pass
  4. 午後 Debut Park／初級區練板（Tower Express 等）
  5. 晚：Ice Village 或 Mina-Mina／木林の湯

2月11日（四）Tomamu → 札幌 · すすきの＋小樽

雪祭最終日：唔係整天提早關大通燈至約22:00；すすきの最終日提早至22:00。
  1. おおぞら4：10:58→12:29（或おおぞら2 08:58→10:41）；正價約¥5,880
  2. Check-in METS，放行李
  3. 時間軸（可行但緊）：12:29到 → 13:30–16:00大通 → 16:00–16:40短訪すすきの → 17:00前後往小樽 → 17:30–20:30あかり → 22:31／23:08前返
  4. 太趕：優先砍すすきの深度（30–40分），保留小樽夜燈

JR／eki-net（外國人）

訪日／海外居住：基本上買正價えきねっと＝日本國內居住者用；海外居住者不能註冊。訪日用 JR-EAST Train Reservation：可買おおぞら／とかち指定席，但係正價（普通車指定席片道約¥5,880），無外國人專屬價，亦無特急トクだ値。
